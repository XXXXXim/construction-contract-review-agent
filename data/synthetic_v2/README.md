# data/synthetic_v2: 평가셋 v2 (SYNTHETIC)

- **전부 합성 데이터**다. 실제 계약서가 아니며 어떤 회사의 자료도 아니다.
- `scripts/make_synthetic.py --dataset v2` 로 생성 (seed=20261104).
- 평가셋 v1(`data/synthetic/`)과 **같은 시드, 같은 변형 24개, 같은 삭제 추첨**에서 출발해 생성기 버그 하나만 고쳤다:
  - 재번호 후 본문 속 계약서 내부 조문 참조("제11조에 따른 서면", "제40조를 준용")를 새 번호로 바꾼다.
    v1 은 비교 가능한 내부 참조 58개 중 54개가 어긋나 있었다 (예: 제11조가 "제11조에 따른 서면"으로 자기 자신을 인용).
  - 남은 조항이 참조하는 조항은 삭제하지 않는다 (v1 은 삭제된 조항을 가리키는 참조 4개). 그래서 계약서 02·03은 조항이 52개다.
  - 「하도급법」 제13조처럼 법령 조문 참조는 바꾸지 않는다.
- **그대로 남긴 것:** 당사자 명칭 치환으로 생기는 조사 어색함(`갑가`, `을는`)은 v1 과 같다. 한 번에 한 가지만 바꿔야 비교가 깨끗하다.
- v1 은 지난 결과 재현을 위해 그대로 둔다 (CLAUDE.md 규칙 9). 결과에는 `set-v1` / `set-v2` 로 구분한다.
