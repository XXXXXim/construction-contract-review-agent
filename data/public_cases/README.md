## 만든 방법
- 제1조~제60조: 표준하도급계약서(2024.12.24) 본문 **그대로** → 이 조항을 지적하면 오탐.
- 제61조: 위 실제 문구를 **원문 그대로** 붙임. 수급사업자명은 의결서에서 이미 비식별 처리(ㅇㅇㅇ)되어 있다.
- 원문 PDF: `data/raw/public_cases/`. 문구 정의·출처·허용 카테고리: `cases.yaml`. 생성: `scripts/make_public_cases.py`.

## 채점 (실제 LLM 실행 전에 고정, 2026-11-08)
- **탐지율:** 제61조를 지적했는가 (카테고리 무관)
- **Recall:** 지적한 카테고리가 `acceptable_categories` 안에 있는가 (공정위 근거는 모두 부당특약 제3조의4, 실질 내용상 대금 지급·하자담보·대금 조정도 허용)
- **오탐:** 제1~60조에 대한 지적
- citation·hit@3 는 대상 아님 (실제 특약에는 "정답 표준 조항"이 없다)

## 한계
- **5건뿐이다.** 1건이 20%p.
- 숫자 규칙이 잡을 수 있는 유형(일수·비율 변경)이 아니어서 규칙 레이어의 효과는 기대하지 않는다.
- 실행 전 관찰: 검색은 제61조를 국토부 표준도급계약서 "제42조(특약사항)"와 짝지어(제목 일치) 대금·하자 조항을 놓치는 경우가 있다 (case 1, 2).
  **결과를 보기 전에는 고치지 않는다** (5건에 맞춘 튜닝 방지). 개선은 별도 실험으로 기록한다.
