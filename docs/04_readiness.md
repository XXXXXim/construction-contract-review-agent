## 교훈 (다음 프로젝트 P3 체크리스트에 반영)
1. **외부 키·데이터·권한은 첫날 실제 명령으로 확인한다.** "나중에 필요하면 말할게요"는 결국 마감 뒤에 막힌다.
2. 세션 환경이 막는 것(정부 사이트, docker 데몬, TLS 프록시)은 개발 전에 목록화한다.
3. 보스에게 받을 것은 흩어서 말하지 말고 **한 번에 표로** 요청한다.
